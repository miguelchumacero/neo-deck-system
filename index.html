neo-ui

Design system de slides/decks de NEO Consulting · canvas 1920×1080 · un solo CSS precompilado.

Ver

Catálogo de componentes — generado desde src/components.css. Cada componente con preview y HTML. Plantilla base de propuesta — deck armado en el orden real que toda propuesta clona. tokens.json — fuente única de color, tipografía, radios y canvas.

Consumir

Un deck linkea un archivo. Pinnea la versión: un deck viejo no se rompe con un cambio del kit.

<link rel="stylesheet" href="https://ESTE-HOST/dist/neo-ui@0.1.0.css">

El alias sin versión (dist/neo-ui.css) apunta siempre al último build — úsalo solo en desarrollo. El CSS trae las fuentes (PT Serif, Montserrat) y los fondos por ruta relativa a este host, con CORS abierto.
